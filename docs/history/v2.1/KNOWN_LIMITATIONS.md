# v2.1.0 已知限制与未通过目标

本文件取代旧版本的当前限制说明，原说明保存在 `history/v2.0/`。不能把本轮已修复内容继续列成“未实现”，也不能把工程测试通过等同于驾驶验收。

| 范围 | 当前真实状态 |
|---|---|
| MetaDrive | DNS 检查失败、缺少运行依赖与匹配 assets；真实执行步数仍是 0。source/assets/wheel 离线校验已实现，但没有真实安装成功、训练和渲染成功证据。 |
| 参考算法 | SB3 参考训练脚本为真实导入和执行路径，尝试因缺依赖失败，不把自研 PPO 替代为 SB3 成功。 |
| 奖励行为 | v3 修复无车直道奖励鼓励两倍速度的具体反例；训练后紧急制动成功率从 25% 降到 14.17%，碰撞升到 85.83%。不是安全改进已全面达标。 |
| 可观测性 | 新 bev_ego 输入与多帧补偿能区分已测试运动状态；旧纯单帧 bev 保留其信息缺陷作消融。姿态来自真值、有限视野历史不能重建此前看不见的障碍，不是完整状态估计。 |
| 视觉能力 | 所有 BEV 来自语义真值；无原始相机、遮挡推断、标定、多传感器重建或学习式世界模型。四帧 PPO 在本轮同预算单种子验证中不如单帧，不能宣传必然增益。 |
| 统计 | 三训练种子用于奖励消融，视觉/MARL/SAC 只有有限工程实验；开发种子已被查看，最终预留 7000–7199 未使用。重复同场景测多策略不增加独立场景数。 |
| MARL | 同一世界学习、集中 critic / 分散 actor 已实测；无 PettingZoo 官方测试通过、无协同通信/RNN/全论文复现，真实 MetaDrive MARL 仍阻塞。 |
| 数据 | 没有下载和验证真实 nuScenes/Waymo。通用许可确认下载、CSV 转换、合成 fixture 与非响应式回放仍只是通用路径。 |
| 恢复 | SAC 完整学习状态恢复已通过下一更新逐位一致测试，actor-only 恢复明确拒绝；PPO/MAPPO/SAC 均不含物理世界快照。SAC 恢复开启新回合，未完成回合可能被丢弃。 |
| 课程 | 旧实测课程未晋级的事实保留；本轮没有完成按跟车/超车/紧急制动重构课程、行为克隆预训练或安全过滤器实验。 |
| 实际标准接口 | 真实 Gymnasium checker 与 4 个 MetaDrive 测试依赖缺失被跳过；不能称 API 获官方认证。TensorBoard UI 与 Docker build 未运行。 |
| 舒适性 | 已增加纵/横向加速度/jerk 和转向率的物理指标及有效覆盖；尚无乘坐舒适行业标准验收。尖峰可能很大，不能用均值掩盖。聚合 p95 是逐回合 p95 均值，不是全局 p95。 |
| 性能 | 本轮 2 车/8 IDM 请求、48像素四帧模式约 306 env step/s，未达到原先所有模式500FPS的目标；不含训练反向或渲染，不跨硬件担保。 |
| 环境 | 沙盒不是专用干净虚拟环境；预装 moviepy 要求 Pillow<12 与当前 Pillow12.3 有冲突，本项目没有使用它。不声称全局 pip check 通过。 |
| 安装信任 | 哈希仅保证对可信清单的一致性，不是供应链签名；离线 wheel 标签通过不代表动态库兼容或依赖闭包通过，仍必须在目标机 pip check、真实导入和 step。源/资产 ZIP 应来自可信来源。 |

本轮交付状态是经过回归测试的 CPU 研究包，不是全部原始需求通过的生产稳定系统。下一行为优先级是诊断紧急制动失败并建立独立训练课程，而不是提高版本号或只扩大训练步数。
