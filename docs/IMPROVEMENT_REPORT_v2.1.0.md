## 2. 控制性缺陷复核

无车直道、目标速度12m/s，仅用油门补偿阻力。原奖励在12/24m/s分别约0.9991/1.8991，超速更有利；新奖励分别0.9991/−0.2509，固定反例已消除。动作和几何相同、收益项有完整记录，见 `reports/v2_1/improvement_audit.json`。这些是单步控制实验，不证明所有轨迹都不存在reward hacking。

几何相同、自车速度8→24m/s时，旧单帧BEV仍完全相同；bev_ego新增motion有1个元素变化。多帧测试还验证终点几何相同、历史车辆运动不同会产生不同历史输入；ego平移/旋转配准、时戳、padding和reset隔离均有测试。姿态为真值，不宣称相机估计。

## 3. 实际训练预算

10次独立启动训练 + 1段SAC恢复，共 **241,664 joint world steps**，**245,799 有效Agent转移**。每种旧/新奖励3种子×32768步共196608；两个视觉配置各16384；两车MAPPO8192；SAC先2048再增加2048。SAC恢复累计4096不能与先2048相加成6144。

所有参数真实更新，权重/优化器/CSV/TFRecord/配置已交付；矩阵提前记录在 `experiments/v2_1/matrix_plan.json`，结果见matrix_results与totals。脚本、单元测试、CLI小样本优化不计入该实验总步数。共11个本轮推理检查点（SAC首次和恢复后都保留），不称11个独立随机种子。

## 7. 阻塞项与后续优先级

DNS阶段失败意味着联网安装未开始依赖解析；不能归因为无GPU或确定Python不兼容。MetaDrive源码0.4.3缺匹配assets；真实MetaDrive本轮0step，SB3缺包。离线校验检查哈希、ABI和版本但不等于目标平台动态库兼容，安装需要真实完成pip check和smoke。

完整限制见KNOWN_LIMITATIONS与acceptance_matrix；当前只能称经过工程回归的CPU研究交付，不能称真实相机/MetaDrive/全原始需求已验收。
